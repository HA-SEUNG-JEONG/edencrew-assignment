# 검색 화면 시안(.lfp) 대조 UI 갭 수정

**날짜**: 2026-09-12
**유형**: fix
**관련 파일**: `lib/ui/search_screen.dart`, `lib/ui/common.dart`

## 변경 내용

관심 화면은 이미 `.lfp` 실측 대조 패스(`2da875d`/`fbf0c3c`,
`docs/fixes/2026-09-12-watchlist-design-gap.md`)를 거쳤지만 검색 화면은 그 대상에서
빠져 있어 한 번도 시안과 수치를 맞춘 적이 없었다. 시안 3장(`검색_empty`, `검색`,
`검색결과_empty`)과 대조해 입력 필드·결과 행·별 아이콘·관심 토스트의 갭만 교정했다.

시안 색상 9종을 ARGB에서 hex로 풀어 `lib/theme/app_palette.dart`와 전부 대조한 결과
**신규 토큰은 필요 없었다**. 빠져 있던 입력 필드 테두리 `#3D3D37`은 이미
`colors.borderStrong`(= `AppPalette.neutral500`)으로 존재했다.

## 주요 구현 사항

### 검색 입력 필드 (`eb15a30`, `5ebb5c2`)

| 항목 | 변경 |
|---|---|
| 외곽 패딩 | `symmetric(horizontal: space4, vertical: space2)` → `fromLTRB(space4, space2, space4, space3)` |
| 테두리 | 없음 → `Border.all(colors.borderStrong, dimens.borderHairline)` |
| 돋보기·X 아이콘 | `iconMd`(20) → `iconSm`(16) |
| 입력·힌트 굵기 | w400 → w500 |
| 높이 | `40` 유지 |

`eb15a30`에서 고정 높이를 빼고 시안의 세로 패딩 10만 주는 방식으로 바꿨더니 글꼴
줄 높이(15pt에서 23)가 더해져 45가 나왔다. 시안 실측 40.4와 어긋나 `5ebb5c2`에서
`height: 40`을 되돌렸다.

### 검색 결과 행·별 아이콘 (`55825f4`)

| 항목 | 변경 |
|---|---|
| 행 높이 | `60` 하드코딩 → 상하 `space2` 패딩 (실측 62 + 헤어라인) |
| 종목명↔부제 간격 | 없음 → `spacing: dimens.space1 / 2` |
| 별 크기 | 18 → 22 (검색 행만) |

시안 SVG path 실측으로 별은 22×22 박스 안에서 x 1.84–20.15(가시 폭 약 18.3)를
차지한다. Material `Icons.star`는 `size: 18`에서 가시 폭이 약 15밖에 안 돼 22가 맞다.

`StarButton`은 자체 `space3` 세로 패딩(터치 영역)을 갖고 있어 22 아이콘이면 박스가
46이 된다. 관심 행처럼 상하 `space3`를 주면 행이 71까지 부푼다. 그래서 우측 패딩을
`space2`로 줄인 기존 관용구와 같은 이유로 세로 패딩도 `space2`로 줄였다.

`StarButton`의 기본값은 18로 두고 검색 행에서만 `size: 22`를 넘긴다. 상세 헤더는
대조할 시안이 없어 기존 크기를 유지했다.

### 관심 토스트 (`2b82a5e`)

| 항목 | 변경 |
|---|---|
| 문구 굵기 | w400 → w700 |
| 별 아이콘 | `iconSm`(16) → 18 (대응 토큰 없음) |
| 가로 패딩 | 리터럴 17 → `dimens.space4`(16) |
| 하단 여백 | `space3` → `space6` |
| 아이콘↔문구 | `space2 + 1` → `space2` |

## 시안 대비 의도적 편차

1. 검색어 일치 구간 보라 강조(`colors.searchHighlight`) — 과제 요구사항, `13fe200`
2. `CircularProgressIndicator` 로딩 상태 — 시안에 없음, 과제 요구사항
3. `Icons.search_off` — 시안의 "돋보기+X" SVG에 가장 가까운 Material 대응물
4. 결과 없음 문구의 곧은 인용부호(`'…'`) vs 시안의 둥근 인용부호(`'…'`)
5. `StarButton` 터치 영역 38×46 — 시안의 별은 여백 없는 22 아이콘이지만 탭 영역이
   필요해 자체 패딩을 유지했다. Material 최소 48에는 못 미치는 기존 편차 그대로

X 지우기 버튼은 검색어가 없어도 그대로 노출한다. 계획 단계에서는 조건부 표시를
검토했지만 시안이 플레이스홀더 상태에서도 X를 그리고 있어 시안을 따랐다.

## 미결

`lib/theme/app_palette.dart`의 `red400`/`redAlpha12`가 `#FF6B5B` → `#FF5B5B`로
바뀐 채 커밋되지 않고 남아 있다. 이번 검색 화면 패스의 변경이 아니라 출처를
확인하기 전까지 커밋하지 않았다.
