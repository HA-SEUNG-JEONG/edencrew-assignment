# 가나다순 정렬에서 한글 종목명을 영문보다 먼저 정렬

**날짜**: 2026-09-12
**유형**: fix (동작 변경 포함)
**관련 파일**: `lib/app_state.dart`, `test/widget_test.dart`

## 문제

`가나다순`은 관심 화면의 기본 정렬이라 앱을 켜면 곧바로 보인다. 그런데
`String.compareTo`는 유니코드 코드포인트 순서라 영문·숫자(`0x41`~)가 한글
음절(`0xAC00`~)보다 항상 작다. 시드 5종목에서 실제로 이렇게 나왔다.

```
LG에너지솔루션
SK하이닉스
삼성전자
에코프로비엠
카카오
```

국어사전·증권 앱 관행은 한글이 먼저다. 첫 화면에서 바로 드러나는 차이라
그대로 두기 어렵다고 판단했다.

## 변경 내용

정렬 키 앞에 한글 여부 플래그(`0`/`1`)를 붙여 한글을 앞세운다.

```dart
// 'LG에너지솔루션'은 코드포인트가 한글보다 작아 그냥 비교하면 가나다순 맨 위로 온다.
// 국어사전 관행대로 한글을 앞세우고 영문·숫자를 뒤로 보낸다
static String _nameKey(String name) {
  final int first = name.isEmpty ? 0 : name.codeUnitAt(0);
  final bool hangul = first >= 0xAC00 && first <= 0xD7A3;
  return '${hangul ? 0 : 1}$name';
}
```

한글 음절 블록 안에서는 코드포인트 순서가 곧 가나다 순서라 추가 처리가 필요 없다.
`intl`의 `Collator` 같은 의존성을 더하지 않고 한 줄 키로 끝냈다.

결과:

```
삼성전자
에코프로비엠
카카오
LG에너지솔루션
SK하이닉스
```
