# 종목 상세 화면 시안 대조 UI 갭 수정

**날짜**: 2026-09-12
**유형**: fix
**관련 파일**: `lib/ui/detail_screen.dart`, `lib/ui/candle_chart.dart`,
`lib/theme/app_colors.dart`, `lib/theme/app_palette.dart`, `lib/theme/README.md`

## 변경 내용

상세 화면은 전용 시안 대조 패스를 받은 적이 없다. 앞선 두 패스
(`watchlist-design-gap`, `watchlist-sort-sheet-empty-state`)는 관심 목록 프레임만 실측했고,
상세 화면의 수치는 거기서 넘겨받거나 눈대중으로 맞춘 값이었다.

이번에는 종목 상세 프레임의 Lucy/Figma 실측값(`figmaRootSize: 393×852`)을 받았다.
검증 기기(iOS Simulator, 393×852)와 논리 해상도가 같아 시안 px 가 Flutter 논리 px 와
1:1로 대응한다 — 배율 환산 없음.

**색상은 거의 전부 맞았다.** 시안의 색상값이 모두 기존 토큰으로 복호화된다
(`4279176974`=`#0F0F0E` `surfaceBase`, `4294638069`=`#FAF9F5` `textPrimary`,
`4290032297`=`#B4B2A9` `textSecondary`, `4280492831`=`#23231F` `borderSubtle`,
`4280032281`=`#1C1C19` `surfaceSunken`, `529235190`=`0x1F8B7CF6` `accentBg`,
`4287331574`=`#8B7CF6` `accentDefault`, `4283276270`=`#4D9BEE` `priceDownText`,
`4284111186`=`#5A5952` `neutral400`).
어긋난 것은 **기하·굵기**와 **토큰 선택 두 건**이었다.

## 앞선 결정 두 건을 뒤집었다

### 1. `red400` `#FF6B5B` → `#FF5B5B` (되돌림)

`2026-09-12-watchlist-sort-sheet-empty-state.md:53` 이 `#FF5B5B` → `#FF6B5B` 로 바꿨었다.
상세 시안 blob 에는 `4294925147`(=`#FF5B5B`)이 57회 나오고 `4294929243`(=`#FF6B5B`)은
한 번도 없다. `lib/theme/README.md:49-58` 도 여전히 `#FF5B5B` 로 적혀 있다.
근거 2 대 1 이라 되돌렸고, 되돌리니 README 가 문서 수정 없이 다시 맞다.
`redAlpha12` 는 파생값이 아닌 별도 리터럴이라 `0x1FFF5B5B` 로 함께 되돌렸다.

영향 범위: `priceUpText`, `priceUpBg`, `chartLineUp`, `chartAreaUp` — 관심·검색·상세 전부.

### 2. 요약 카드 라벨 · 표 헤더 `textTertiary` → `textSecondary`

`2026-09-12-watchlist-design-gap.md` 는 `detail_screen.dart:324`(요약 카드 라벨)와
`:396`(표 헤더)의 `textTertiary`(#888780)를 **의도적으로 유지**했다고 기록했다.
그 판단은 상세 시안이 없는 상태에서 내린 것이고, 시안은 두 곳 모두
`4290032297` = `#B4B2A9` = `textSecondary` 라고 말한다. 시안이 우선이다.

## 주요 구현 사항

### 헤더

| 항목 | 시안 | 이전 | 변경 |
|---|---|---|---|
| 뒤로 화살표 색 | `#B4B2A9` | `textPrimary` | `textSecondary` |
| 화살표 좌측 여백 | 16 (중심 x=26) | IconButton 기본 48 박스 | 좌측 패딩 `space1` + 44 박스 |
| 종목명 시작 x | 48 | 48 (우연히 일치) | 유지 |
| 종목명↔코드 간격 | 1 | 없음 | `spacing: 1` |
| 별 아이콘 | 22 | 18 | `StarButton(size: 22)` |

시안의 아이콘 박스는 20 이지만 탭 영역은 44 로 남겼다 — **의도된 편차**.
`padding: EdgeInsets.zero` + `constraints: 44×44` + `tapTargetSize: shrinkWrap` 조합이라야
Material 3 이 48 로 다시 부풀리지 않는다. 좌측 패딩 4 + 44 = 48 이 시안의 종목명 시작점이다.

`StarButton` 은 검색 행과 공유한다. 공용 기본값(18)은 건드리지 않고 상세 호출부에서
`size: 22` 를 넘긴다. 검색 행도 `55825f4` 에서 같은 값을 넘기므로 기본값 18 은
현재 사용처가 없다.

### 본문 간격

시안 본문은 `Padding(top 14, left 16, right 16, bottom 16)` 위의 `Column(spacing: 24)`.

| 경계 | 시안 | 이전 | 변경 |
|---|---|---|---|
| 헤더 → 현재가 | 14 | `space5`(20) | 리터럴 14 |
| 현재가 → 기간 칩 | 16 | `space4`(16) | 유지 |
| 기간 칩 → 차트 | 24 | `space5`(20) | `space6` |
| 차트 → 요약 카드 | 24 | `space5`(20) | `space6` (같은 패딩) |
| 요약 카드 → 일별 시세 | 24 | `space6`(24) | 유지 |
| 일별 시세 → 표 헤더 | 4 | `space3`(12) | `space1` |
| 마지막 행 → 바닥 | 16 | 없음 | `ListView(padding: bottom space4)` |

### 현재가 행

시안은 `"▼ 400 (-0.22%)"` 가 **15/w500 한 덩어리**다. 화살표를 별도 `Text` +
`Padding(right: 4)` 으로 떼어 놓았던 것을 문자열로 합치고 `Padding` 을 지웠다.
행 간격도 `space3`(12) + 화살표 여백 4 = 실효 16 이던 것을 `space2`(8)로 맞췄다.
굵기는 w700 → w500.

### 기간 칩

| 항목 | 시안 | 이전 |
|---|---|---|
| 칩 사이 간격 | 4 | 0 → `Row(spacing: space1)` |
| 글자 크기 | 13 | 12 |
| 선택 굵기 | w400 | w500 → 두 상태 모두 `regular` |

높이 28, `Expanded` 균등 분할, `accentBg`/`accentDefault` 는 이미 맞았다.

### 캔들 차트

| 항목 | 시안 | 이전 | 변경 |
|---|---|---|---|
| 높이 | 200 | 152 | 200 (로딩 자리표시자도 함께) |
| 꼬리 색 | `#5A5952` 회색, 등락 무관 | 몸통과 같은 색 | `chartWick` 토큰 신설 |
| 몸통 : 슬롯 | 4.8 : 6.0 = 0.8 | 0.6 | 0.8 |

`lib/theme/README.md` 에 `chart/wick` 행을 추가했다.

| 항목 | 시안 | 이전 |
|---|---|---|
| 제목 굵기 | w700 | w500 |
| 헤더 글자색 | `#B4B2A9` | `textTertiary` |

구분선은 `DailyTableRow` 에 `showBorder` 를 더해 `Border(top:)` 으로 바꾸고

컬럼은 `_flex` 를 지우고 `[Text(날짜), Expanded×3]` + `Row(spacing: space2)` 로 바꿨다.
361 폭에서 날짜 칸이 77 → 약 28 로 줄고 종가가 77 → 약 103 으로 늘어난다.

## 시안대로 두지 않은 것

- **꼬리 두께 0.3** — 서브픽셀. 1.0 유지.
- **아이콘 탭 영역** — 시안 20, 구현 44.
- **1개월 캔들 약 50개** — 시안은 Figma 목업 구조일 뿐이고 실제 데이터는 거래일 20일
  (`Period.month1.pages = 2`). `Period.pages` 는 건드리지 않았다.
- **`crossAxisAlignment: start` + 위쪽 꼬리만 있는 캔들** — 목업의 박스 스택이
  그대로 익스포트된 흔적. 고가/저가 양방향 꼬리를 유지했다.

## 알려진 편차

날짜 칸이 시안대로 글자 폭을 쓰기 때문에 헤더(`날짜`, 약 22)와 본문(`09.11`, 약 28)의
폭이 달라 가운데 두 칸(종가·등락)의 우측 끝이 헤더와 본문 사이에서 **약 4 어긋난다**.
거래량 칸은 양쪽 다 x=377 에 정확히 붙는다. 시안도 같은 구조라 그대로 두고
`DailyTableRow` 주석에 남겼다.
